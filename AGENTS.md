# Continuidad del desarrollo

Lee `docs/PROJECT_MEMORY.md` antes de continuar este proyecto.
El usuario autoriza continuar el desarrollo y las verificaciones rutinarias sin
pedir confirmación en cada iteración. Completa cambios concretos y comprobables.
El usuario ha pedido retirar la igualación de volumen de la aplicación. La
comparación visible es DSP activado/desactivado, sin compensación. Las pruebas
internas pueden normalizar niveles. Conserva el perfil favorito aprobado.
